Known gaps and live-validation status

Area Status What remains
Deployment connectivity Healthy heartbeat The gateway reports a fresh outbound sync and SCM marks the deployment healthy. On-demand ping() remains unreachable by design because it requires control-plane-initiated ingress to the private data plane.
MCP workspace binding Live verified Request shape and strict empty response schema were captured with a disposable integration.
Write request contracts Live verified Every body-taking operation validates an exported Zod schema before OAuth or fetch. Config update semantics, routing round-trip, and regular integration binding shape passed live conformance.
Other generic writes Response schema loose Some integration, workspace, plugin, and API-key create/update responses still use a permissive passthrough schema until live receipts are recorded.
Plugins Incomplete CRUD Probe get/update/delete routes before adding methods.
Inference Not started Runtime authentication, streaming, uploads, routing headers, and OpenAI-compatible wire behavior require gateway-level validation.

Remaining roadmap

1 · Finish private-path validation. Run a real gateway request from an authorized in-cluster workload, then confirm the resulting request in SCM telemetry. Do not expose the gateway publicly merely to satisfy ping().
2 · Tighten write response schemas. Record redacted live fixtures and replace remaining GatewayWriteResponse placeholders with resource-specific response types.
3 · Phase 2 administration. Add MCP servers, usage/rate-limit policies, secret references, users, invitations, and membership operations—only after SCM route probes.
4 · Phase 3 authoring. Research collections, labels, prompts/versions/partials, feedback, log detail, and exports.
5 · Phase 4 inference. Design a separate inference client after runtime auth, streaming, binary payload, and compatibility contracts are proven.
6 · Release sequence. Commit/review SDK changes, publish the SDK, update and install the CLI dependency, validate CLI/docs, then release the CLI.
